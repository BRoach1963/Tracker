# Dashboard

The Dashboard is your command center - a single view of everything important happening with your team.

## Dashboard Overview

The Dashboard provides at-a-glance visibility into:
- Upcoming activities
- Team health metrics
- Task status
- OKR progress
- KPI performance
- Recent changes

## Dashboard Sections

### 📅 Upcoming 1:1 Meetings

**What it shows**:
- Next 7 days of scheduled 1:1s
- Team member names
- Meeting dates and times
- Quick status (Scheduled, Confirmed)

**Actions**:
- Click to view meeting details
- See if agenda is prepared
- Identify meetings needing prep

**Alerts**:
- ⚠️ Meeting today with no agenda items
- ⚠️ Team member hasn't had 1:1 in 2+ weeks

### ✅ Task Summary

**What it shows**:
- **Overdue**: Tasks past their due date
- **Due Today**: Action needed now
- **Due This Week**: Coming up soon
- **Total Active**: All incomplete tasks

**Color Coding**:
- 🔴 Overdue (needs immediate attention)
- 🟡 Due today
- 🟢 On track

**Actions**:
- Click counts to see task list
- Quick complete from dashboard
- Reassign overdue tasks

### 👥 Team Overview

**What it shows**:
- Total team members
- Active vs. away/leave
- New hires (last 30 days)
- Recent departures

**Quick Stats**:
- Average tenure
- Department breakdown
- Recent 1:1 coverage

### 📊 OKR Progress

**What it shows**:
- Current quarter OKRs
- Progress percentages
- Status indicators (On Track/At Risk/Off Track)
- Days remaining in period

**Visualization**:
- Progress bars by objective
- Key Result summary
- Trend arrows (improving/declining)

**Actions**:
- Click to see OKR details
- Quick update progress
- Identify at-risk objectives

### 📈 KPI Health

**What it shows**:
- Key metrics at a glance
- Current vs. target values
- Status indicators
- Last update date

**Color Coding**:
- 🟢 On Target
- 🟡 Close to Target (within 10%)
- 🔴 Off Target

**Actions**:
- Click to see KPI details
- Update values
- View trend charts

### 🕐 Recent Activity

**What it shows**:
- Latest changes across all areas
- Who made changes
- What was changed
- When it happened

**Activity Types**:
- Tasks completed
- 1:1s held
- Feedback given
- Goals updated
- OKR progress changes

## Dashboard Alerts

### Alert Types

| Alert | Trigger | Priority |
|-------|---------|----------|
| Overdue Tasks | Any task past due | High |
| 1:1 Gap | No 1:1 in 14+ days | High |
| OKR At Risk | Progress < 40% | Medium |
| KPI Off Target | Value below threshold | Medium |
| Missing Feedback | No feedback in 30 days | Low |
| Goal Stale | No update in 30 days | Low |

### Alert Actions
- **Dismiss**: Remove for now
- **Snooze**: Remind later
- **Act**: Go fix the issue
- **Settings**: Adjust thresholds

## Troubleshooting

### Dashboard Not Loading
1. Refresh the page
2. Check internet connection
3. Clear browser cache
4. Try different browser

### Data Seems Wrong
1. Check last sync time
2. Verify source data
3. Refresh manually
4. Check filters applied

### Slow Performance
1. Reduce widget count
2. Narrow date range
3. Check system resources
4. Close other tabs
