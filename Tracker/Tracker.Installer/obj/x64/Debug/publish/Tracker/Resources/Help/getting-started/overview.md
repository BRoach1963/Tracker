# Welcome to Tracker

Tracker is a comprehensive team management application designed to help managers effectively track and develop their team members.

## Key Features

- **Team Management** - Maintain profiles for all team members including their roles, skills, and contact information
- **1:1 Meetings** - Schedule, track, and document one-on-one meetings with actionable follow-ups
- **Tasks** - Create and assign tasks to team members with due dates and status tracking
- **Projects** - Manage projects with milestones and team assignments
- **OKRs** - Set and track Objectives and Key Results for your team
- **KPIs** - Monitor Key Performance Indicators to measure team success
- **Goals** - Track individual development goals for team members
- **Feedback** - Document positive feedback and coaching moments

## Getting Started

1. **First Login** - Log in with your credentials to access your dashboard
2. **Add Team Members** - Start by adding your direct reports to the system
3. **Schedule 1:1s** - Set up recurring one-on-one meetings
4. **Create Tasks** - Assign tasks and track progress

## Navigation

Use the sidebar on the left to navigate between different sections:

| Section | Description |
|---------|-------------|
| Dashboard | Overview of your team's status and upcoming items |
| Team Members | Manage your team roster |
| 1:1s | One-on-one meeting management |
| Tasks | Task tracking and assignment |
| Projects | Project management |
| OKRs | Objectives and Key Results |
| KPIs | Key Performance Indicators |

| Key | Action |

| **F1** | Open context-sensitive help |
