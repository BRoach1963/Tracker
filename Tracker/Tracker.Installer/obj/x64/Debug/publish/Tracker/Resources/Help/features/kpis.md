# KPIs (Key Performance Indicators)

Monitor Key Performance Indicators to track ongoing metrics.

## Overview

KPIs measure ongoing performance metrics that matter to your team:

- **Name** - What you're measuring
- **Current Value** - Latest measurement
- **Target Value** - Goal to achieve
- **Status** - Green/Amber/Red based on performance

## KPIs vs OKRs

| Aspect | KPIs | OKRs |
|--------|------|------|
| **Duration** | Ongoing | Time-bound |
| **Focus** | Maintenance | Achievement |
| **Change** | Monitor | Improve |
| **Example** | "Uptime ≥ 99.9%" | "Increase uptime to 99.99%" |

## Creating a KPI

1. Navigate to **KPIs** in the sidebar
2. Click **Add KPI**
3. Enter KPI details:
   - **Name** - Clear metric name
   - **Description** - What it measures
   - **Target Value** - Goal
   - **Current Value** - Latest reading
   - **Owner** - Who tracks it
4. Optionally link to an OKR
5. Click **Save**

## Status Calculation

KPI status is automatically calculated:

- 🟢 **Green** - Current ≥ Target
- 🟡 **Amber** - Current ≥ 80% of Target  
- 🔴 **Red** - Current < 80% of Target

## Linking KPIs

### To OKRs

KPIs can serve as Key Results for OKRs:

1. When creating a KPI, select the parent OKR
2. KPI progress contributes to OKR progress

### To Projects

Track project-specific metrics:

1. Associate KPI with a project
2. Monitor project health through KPIs

### In 1:1s

Review KPIs during meetings:

1. Link KPI to meeting
2. Discuss trends and variances
3. Create action items for improvements

## Example KPIs

| Type | Example |
|------|---------|
| **Quality** | Bug escape rate, Code coverage |
| **Delivery** | Sprint velocity, On-time delivery |
| **Team** | Employee satisfaction, Turnover rate |
| **Customer** | NPS score, Response time |

## Best Practices

> 💡 **Measure what matters** - Don't track everything, focus on key metrics.

> 💡 **Update regularly** - Stale data is useless data.

> 💡 **Act on red** - KPIs should drive action.

> 💡 **Review trends** - Look at direction, not just current state.
