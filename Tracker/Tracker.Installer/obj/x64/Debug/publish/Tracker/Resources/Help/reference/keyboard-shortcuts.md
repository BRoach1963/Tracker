# Keyboard Shortcuts

Tracker supports keyboard shortcuts for common actions to help you work more efficiently.

## Global Shortcuts

| Shortcut | Action |
|----------|--------|
| **F1** | Open context-sensitive help |
| **Ctrl+N** | Create new item (context-dependent) |
| **Ctrl+S** | Save current item |
| **Ctrl+F** | Focus search/filter |
| **Escape** | Close dialog or cancel action |

## Navigation

| Shortcut | Action |
|----------|--------|
| **Ctrl+1** | Go to Dashboard |
| **Ctrl+2** | Go to Team Members |
| **Ctrl+3** | Go to 1:1s |
| **Ctrl+4** | Go to Tasks |
| **Ctrl+5** | Go to Projects |

## In Dialogs

| Shortcut | Action |
|----------|--------|
| **Enter** | Confirm/Save (when button focused) |
| **Escape** | Cancel and close |
| **Tab** | Move to next field |
| **Shift+Tab** | Move to previous field |

## In Grids/Lists

| Shortcut | Action |
|----------|--------|
| **Up/Down Arrow** | Navigate rows |
| **Enter** | Open selected item |
| **Delete** | Delete selected item (with confirmation) |
| **Ctrl+A** | Select all |

## Help Window

| Shortcut | Action |
|----------|--------|
| **Alt+Left** | Go back |
| **Alt+Right** | Go forward |
| **Ctrl+Home** | Go to home/index |
| **Ctrl+F** | Focus search |
| **Ctrl++** | Zoom in |
| **Ctrl+-** | Zoom out |
| **Ctrl+0** | Reset zoom to 100% |
| **Escape** | Close help window |

## Tips

> 💡 **F1 is your friend** - Press F1 anywhere for contextual help about your current screen.

> 💡 **Tab through dialogs** - Use Tab to quickly move between fields instead of clicking.

> 💡 **Escape to cancel** - Press Escape to quickly close any dialog without saving.
