# Add OKR Dialog

Create or edit Objectives and Key Results.

## Overview

Set team objectives with measurable key results.

## Fields

### Objective

| Field | Description |
|-------|-------------|
| **Title** | What you want to achieve |
| **Description** | Additional context |
| **Owner** | Team member responsible |
| **Start Date** | When the OKR period begins |
| **End Date** | When it should be achieved |

### Key Results

Each Key Result includes:

| Field | Description |
|-------|-------------|
| **Description** | What you'll measure |
| **Target Value** | The goal number |
| **Current Value** | Progress so far |

## Adding Key Results

1. Click **Add Key Result**
2. Enter description (make it measurable!)
3. Set target value
4. Set starting current value (usually 0)

## Tips

> 💡 **3-5 Key Results per Objective** - Don't overload.

> 💡 **Measurable** - "Increase X from Y to Z"

> 💡 **Ambitious but achievable** - 70% completion = success
