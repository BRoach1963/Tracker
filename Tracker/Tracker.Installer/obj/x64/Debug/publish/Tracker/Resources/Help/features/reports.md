# Reports

Reports help you analyze team data, track trends, and share insights with stakeholders.

## Report Types

### Team Reports

#### Team Overview Report
Summary of your entire team:
- Headcount and composition
- Tenure distribution
- Role breakdown
- Recent changes (joins/departures)

#### 1:1 Coverage Report
Meeting cadence analysis:
- Meetings per team member
- Average meeting frequency
- Gaps in coverage
- Meeting duration stats

### Performance Reports

#### Task Performance Report
Work completion analysis:
- Tasks completed over time
- On-time completion rate
- Average cycle time
- Completion by owner

#### OKR Progress Report
Objective tracking:
- Progress by objective
- Key Result achievements
- Status distribution
- Quarter-over-quarter trends

#### KPI Scorecard
Metric summary:
- All KPIs with current values
- Target vs. actual
- Trend indicators
- Category groupings

### Activity Reports

#### Feedback Report
Feedback analysis:
- Feedback count by type
- Distribution by team member
- Feedback over time
- Follow-up completion

#### Goal Progress Report
Development tracking:
- Active goals by person
- Completion rates
- Category distribution
- Milestone progress

## Generating Reports

### Quick Reports
1. Go to **Chronicle** → **Reports**
2. Select report type
3. Choose date range
4. Click **Generate**
5. View instantly

### Customized Reports
1. Click **Custom Report**
2. Select data elements
3. Choose groupings
4. Set filters
5. Configure visualizations
6. Generate and save

## Report Parameters

### Date Ranges
| Option | Description |
|--------|-------------|
| This Week | Last 7 days |
| This Month | Current month |
| This Quarter | Current quarter |
| This Year | Current year |
| Last Quarter | Previous quarter |
| Custom | Specific date range |

### Filters
Narrow your report:
- By team member
- By department
- By project
- By status
- By priority
- By date range

### Groupings
Organize data by:
- Team member
- Time period (day/week/month)
- Category
- Status
- Project

## Report Visualizations

### Charts Available
- **Bar Charts**: Compare values across categories
- **Line Charts**: Show trends over time
- **Pie Charts**: Show distribution/composition
- **Progress Bars**: Completion percentages
- **Tables**: Detailed data rows

### Visualization Tips
- Use bar charts for comparisons
- Use line charts for trends
- Use pie charts sparingly (5 segments max)
- Include context (targets, benchmarks)

## Report Sections

### Building Custom Reports

## Specific Report Details

### Weekly Team Summary
**Includes**:
- Tasks completed this week
- 1:1s held
- Feedback given
- OKR progress updates
- Upcoming deadlines

**Best for**: Your own weekly review

### Monthly Performance Dashboard
**Includes**:
- Task completion rates
- OKR status breakdown
- KPI scorecard
- Team activity metrics
- Highlights and concerns

**Best for**: Sharing with your manager

### Quarterly OKR Review
**Includes**:
- All OKRs and progress
- Key Result details
- What worked/didn't
- Next quarter preview

**Best for**: Quarter-end reviews

### 1:1 Preparation Pack
**Includes** (per team member):
- Recent feedback
- Task status
- Goal progress
- Previous meeting notes
- Suggested topics

**Best for**: Before 1:1 meetings

## Report Insights

### Automatic Insights
Reports highlight:
- Notable achievements
- Areas of concern
- Trends (improving/declining)
- Anomalies

### Insight Types
- 📈 "Task completion up 15% this month"
- ⚠️ "3 team members haven't had 1:1s in 2 weeks"
- 🎉 "All OKRs on track this quarter"
- 📉 "Average task cycle time increased"

## Best Practices

### Report Frequency
| Report Type | Suggested Cadence |
|-------------|-------------------|
| Task summary | Weekly |
| 1:1 coverage | Weekly |
| OKR progress | Bi-weekly |
| KPI scorecard | Monthly |
| Team overview | Quarterly |

### Making Reports Actionable
1. Include context, not just data
2. Highlight what's changed
3. Call out what needs attention
4. Suggest next steps
5. Make comparisons (period over period)

### Report Hygiene
- Archive old reports
- Delete duplicates
- Keep templates updated
- Review scheduled reports quarterly

## Troubleshooting

### Report Shows No Data
- Check date range
- Verify filters aren't too narrow
- Ensure data exists for period
- Check permissions

### Report Is Slow
- Reduce date range
- Simplify groupings
- Remove unnecessary sections
- Try during off-peak hours

### Data Doesn't Match Expectations
- Verify source data accuracy
- Check filter settings
- Review grouping logic
- Confirm date ranges
