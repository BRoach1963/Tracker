# Reports

Export your data for analysis and sharing.

## Overview

The Reports section allows you to:

- Export data to Excel
- Generate summaries
- Share information with stakeholders
- Back up your data

## Available Reports

### Team Members Export

Export team roster including:
- Names and contact info
- Roles and tenure
- Status

### 1:1 Meetings Export

Export meeting history:
- All meetings with details
- Agenda items discussed
- Tasks created
- Linked items

### Tasks Export

Export task data:
- All tasks with status
- Due dates
- Owners
- Completion status

### Projects Export

Export project information:
- Project details
- Milestones
- Status and progress

### OKRs Export

Export OKR data:
- Objectives with Key Results
- Progress metrics
- Status

### KPIs Export

Export KPI metrics:
- Current and target values
- Status indicators
- Historical data

### Full Export

Export all data:
- Complete data backup
- All entities included
- Good for migration or backup

## Generating Reports

1. Navigate to **Reports** in the sidebar
2. Select the report type
3. Click the **Export** button
4. Choose save location
5. Open in Excel

## Export Format

All exports are in Excel format (.xlsx):

- Properly formatted columns
- Headers included
- Ready for analysis
- Can be filtered and sorted in Excel

## Use Cases

### Performance Reviews

1. Export team member data
2. Export feedback history
3. Export goal progress
4. Compile for review meetings

### Status Updates

1. Export projects
2. Export OKRs
3. Share with leadership

### Data Backup

1. Use Full Export
2. Save to secure location
3. Run regularly

## Best Practices

> 💡 **Regular backups** - Export full data periodically.

> 💡 **Secure storage** - Exports contain sensitive data.

> 💡 **Before reviews** - Export relevant data in advance.
