# Individual Goals

Individual Goals track personal and professional development objectives for your team members.

## Goals vs. OKRs

| Aspect | Goals | OKRs |
|--------|-------|------|
| **Focus** | Individual growth | Team/org outcomes |
| **Scope** | Personal development | Business results |
| **Timeline** | Flexible | Quarter/Year bound |
| **Ownership** | Single person | Can be team-owned |
| **Measurement** | Often qualitative | Always quantitative |

## Creating a Goal

1. Navigate to **Circle** → **Goals**
2. Click **+ Add Goal**
3. Fill in goal details:

| Field | Description |
|-------|-------------|
| **Title** | Clear, concise goal statement |
| **Description** | Context, motivation, approach |
| **Team Member** | Who this goal is for |
| **Category** | Type of goal |
| **Target Date** | When to achieve by |
| **Status** | Current progress state |
| **Milestones** | Steps toward completion |

## Writing Effective Goals

### SMART Framework

| Letter | Meaning | Example |
|--------|---------|---------|
| **S** | Specific | "Complete AWS Solutions Architect certification" |
| **M** | Measurable | "Score 80% or higher on exam" |
| **A** | Achievable | Realistic given resources/time |
| **R** | Relevant | Aligns with career path |
| **T** | Time-bound | "By end of Q2 2025" |

### Goal Statement Examples

✅ **Good Goals**:
- "Earn PMP certification by June 2025"
- "Lead 3 cross-functional projects this year"
- "Improve public speaking: present at 2 team meetings monthly"
- "Reduce code review turnaround time to under 4 hours"

❌ **Poor Goals**:
- "Get better at my job"
- "Learn more things"
- "Be more organized"

## Goal Status

| Status | Meaning |
|--------|---------|
| **Not Started** | Goal set, work not begun |
| **In Progress** | Actively working toward goal |
| **At Risk** | Behind schedule, needs attention |
| **Completed** | Goal achieved |
| **Cancelled** | No longer pursuing |
| **Deferred** | Pushed to later period |

## Milestones

Break goals into checkpoints:

### Example: "Earn PMP Certification"
1. ☐ Complete 35 hours of PM education
2. ☐ Submit application to PMI
3. ☐ Schedule exam date
4. ☐ Complete practice exams (80%+ average)
5. ☐ Pass PMP exam

### Milestone Best Practices
- 3-7 milestones per goal
- Each independently achievable
- Clear completion criteria
- Logical progression

## Tracking Progress

### Progress Updates
1. Open the goal
2. Click **Update Progress**
3. Add notes on what's changed
4. Update milestone status
5. Adjust status if needed

### Progress History
All updates are logged:
- Date of update
- What changed
- Notes provided
- Who updated

## Goals in 1:1 Meetings

### Discussing Goals
Add goal discussions to your 1:1 agenda:
1. Create agenda item
2. Link to specific goal
3. Discuss progress
4. Document blockers
5. Plan next steps

### Goal Review Cadence
- **Weekly**: Quick check-in during 1:1
- **Monthly**: Detailed progress review
- **Quarterly**: Goal adjustment/setting
- **Annually**: Year-end review

## Manager's Role

### Setting Goals
- Collaborate, don't dictate
- Align with career aspirations
- Balance stretch and achievability
- Ensure resources available

### Supporting Progress
- Regular check-ins
- Remove blockers
- Provide resources
- Celebrate milestones

### Adjusting Goals
When to modify:
- Circumstances change
- New priorities emerge
- Original goal was wrong
- Achieved early (raise the bar!)

### Goal Achievement Tracking

- Goal complexity ratings
- Year-over-year trends

### Performance Reviews
Use goal data in reviews:
1. Pull goal history
2. Review completion rates
3. Discuss challenges
4. Set next period goals

## Best Practices

### For Managers
1. **Limit quantity** - 3-5 goals per quarter max
2. **Balance types** - Mix of skill, performance, career
3. **Check in regularly** - Don't wait for reviews
4. **Celebrate wins** - Acknowledge achievements
5. **Learn from misses** - Goals not met teach us too

### For Goal Setting Conversations
- Ask about aspirations first
- Listen more than talk
- Make goals collaborative
- Document clearly
- Follow up consistently
