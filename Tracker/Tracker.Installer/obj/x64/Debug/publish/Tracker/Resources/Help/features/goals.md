# Individual Goals

Track personal development goals for team members.

## Overview

Individual goals focus on personal and professional growth:

- **Title** - What they're working toward
- **Category** - Type of development
- **Status** - Progress state
- **Target Date** - When to achieve by
- **Progress** - Percentage complete

## Goal Categories

| Category | Focus |
|----------|-------|
| **Career** | Promotion, role change |
| **Skill Development** | Learning new skills |
| **Certification** | Formal credentials |
| **Leadership** | Management skills |
| **Communication** | Soft skills |
| **Technical** | Technical expertise |
| **Personal** | Work-life balance |

## Creating a Goal

1. Open a **Team Member** profile
2. Go to the **Goals** tab
3. Click **Add Goal**
4. Fill in:
   - **Title** - Clear goal statement
   - **Category** - Type of goal
   - **Description** - Details and context
   - **Target Date** - Deadline (optional)
   - **Progress** - Starting percentage
5. Add **Milestones** (optional):
   - Key checkpoints toward the goal
   - Mark complete as achieved
6. Click **Save**

## Goal Statuses

| Status | Meaning |
|--------|---------|
| **Not Started** | Goal created but work hasn't begun |
| **In Progress** | Actively working on it |
| **On Track** | Progress is on schedule |
| **At Risk** | May not meet target date |
| **Completed** | Goal achieved |
| **On Hold** | Temporarily paused |
| **Cancelled** | No longer pursuing |

## Managing Goals

### Updating Progress

1. Open the goal
2. Adjust the progress slider
3. Add notes about what's been done
4. Mark milestones complete

### In 1:1s

Goals are perfect 1:1 discussion topics:

1. Review progress on existing goals
2. Discuss blockers and support needed
3. Create action items to help
4. Celebrate completions

## Best Practices

> 💡 **SMART goals** - Specific, Measurable, Achievable, Relevant, Time-bound.

> 💡 **Not too many** - 3-5 active goals maximum.

> 💡 **Regular check-ins** - Review in every 1:1.

> 💡 **Support, don't just track** - Help remove obstacles.
