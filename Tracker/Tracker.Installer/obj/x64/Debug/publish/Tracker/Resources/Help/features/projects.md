# Projects

Track team projects with milestones, risks, and dependencies.

## Overview

Projects in Tracker provide a lightweight project management view focused on team oversight rather than deep project management.

Each project includes:

- **Name** - Project title
- **Description** - What the project is about
- **Owner** - Team member responsible
- **Status** - Current state (Active, On Hold, Completed)
- **Dates** - Start and end dates
- **Progress** - Completion percentage

## Creating a Project

1. Navigate to **Projects** in the sidebar
2. Click **Add Project**
3. Fill in the details:
   - **Name** (required)
   - **Description**
   - **Owner** - Select team member
   - **Start Date**
   - **End Date** (optional)
   - **Status**
4. Click **Save**

## Project Details

### Milestones

Track key deliverables and checkpoints:

- Add milestones with target dates
- Mark as complete when achieved
- Visual timeline view

### Risks

Document and track project risks:

- Risk description
- Impact level (High/Medium/Low)
- Mitigation plan
- Status

### Dependencies

Link related projects:

- Identify blocking dependencies
- Track cross-project impacts

## Managing Projects

### Updating Progress

- Open project and adjust progress slider
- Progress auto-calculates from milestone completion

### Changing Status

- **Active** - Work in progress
- **On Hold** - Temporarily paused
- **Completed** - Finished
- **Cancelled** - No longer needed

## Linking to 1:1s

Discuss project status in meetings:

1. In a 1:1, go to **Linked Items**
2. Add the project
3. Project status visible during discussion

## Best Practices

> 💡 **Keep it high-level** - Use Tracker for oversight, not detailed task tracking.

> 💡 **Update regularly** - Refresh project status before 1:1s.

> 💡 **Track blockers** - Use risks to document issues.
