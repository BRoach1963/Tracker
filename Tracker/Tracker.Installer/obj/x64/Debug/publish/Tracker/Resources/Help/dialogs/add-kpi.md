# Add KPI Dialog

Create or edit Key Performance Indicators.

## Overview

Track ongoing performance metrics.

## Fields

| Field | Description |
|-------|-------------|
| **Name** | What you're measuring |
| **Description** | Details about the metric |
| **Target Value** | Goal to achieve |
| **Current Value** | Latest measurement |
| **Owner** | Who tracks this KPI |
| **Link to OKR** | Optional parent OKR |

## Status Calculation

Status is automatic based on current vs target:

- 🟢 **Green** - Current ≥ Target
- 🟡 **Amber** - Current ≥ 80% of Target
- 🔴 **Red** - Current < 80% of Target

## Linking to OKRs

KPIs can serve as Key Results:

1. Select a parent OKR
2. KPI progress contributes to OKR progress

## Tips

> 💡 **Keep it simple** - One number, one target

> 💡 **Update regularly** - Stale data is useless

> 💡 **Act on red** - KPIs should drive action
