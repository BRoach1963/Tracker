# Tasks

Tasks help you track action items and follow-ups for your team members. They can be standalone or linked to 1:1 meetings.

## Overview

Each task includes:

- **Description** - What needs to be done
- **Owner** - Who is responsible
- **Due Date** - When it should be completed
- **Status** - Open or Completed

## Creating Tasks

### From the Tasks Page

1. Navigate to **Tasks** in the sidebar
2. Click **Add Task**
3. Enter the task description
4. Select the owner (team member)
5. Set the due date
6. Click **Save**

### From a 1:1 Meeting

1. Open a 1:1 meeting
2. Go to the **Tasks** tab
3. Click **Add Task**
4. The task is automatically linked to the meeting

## Managing Tasks

### Completing a Task

- Click the checkbox next to the task, or
- Open the task and change status to **Completed**

### Editing a Task

- Double-click the task row, or
- Select and click **Edit**

### Deleting a Task

- Select the task and click **Delete**
- Confirm the deletion

## Task Views

### All Tasks

The main Tasks view shows all tasks across all team members.

### By Team Member

View tasks for a specific team member from their profile.

### By Meeting

See tasks created from a specific 1:1 in the meeting details.

## Filtering and Sorting

- **Filter by Status** - Show All, Open, or Completed
- **Filter by Owner** - Show tasks for specific team member
- **Sort by Due Date** - See what's coming up

## Best Practices

> 💡 **Create actionable tasks** - Be specific about what needs to be done.

> 💡 **Set realistic due dates** - Consider workload and dependencies.

> 💡 **Follow up in 1:1s** - Review task progress during meetings.

> 💡 **Close completed tasks promptly** - Keep the list current.
