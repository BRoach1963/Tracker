# Quick Notes

Quick Notes provide a fast way to capture thoughts, ideas, and information that doesn't fit elsewhere.

## When to Use Quick Notes

### Good For
- Fleeting thoughts you want to remember
- Meeting observations
- Ideas for later
- Temporary reminders
- Draft content
- Personal reflections

### Better Elsewhere
- Task assignments → Tasks
- 1:1 discussions → Meeting Notes
- Performance observations → Feedback
- Project details → Project description
- Formal documentation → Reports

## Creating Quick Notes

### Quick Capture
1. Press `Ctrl+Shift+N` anywhere in the app
2. Or go to **Chronicle** → **Notes**
3. Click **+ New Note**
4. Type your content
5. Auto-saves as you type

### Note Properties

| Field | Description |
|-------|-------------|
| **Title** | Brief headline (auto-generated if blank) |
| **Content** | The note body |
| **Created** | Timestamp (automatic) |
| **Tags** | Categorization labels |
| **Color** | Visual organization |
| **Pinned** | Keep at top |

## Note Content

### Rich Text Support
Format your notes with:
- **Bold** and *italic*
- Bullet lists
- Numbered lists
- Checkboxes ☐ ☑
- Headers
- Links

### Checklist Notes
Create mini task lists:
```
☐ Call vendor about renewal
☐ Draft email to team
☐ Review budget numbers
☑ Submit expense report
```

### Code and Technical Notes
Use code blocks for technical content:
```
SELECT * FROM users
WHERE active = true
```

## Organizing Notes

### Tags
Add tags for categorization:
- #project-alpha
- #idea
- #follow-up
- #reference
- #meeting

**Using Tags**:
1. Type `#` followed by tag name
2. Or click **Add Tag**
3. Select existing or create new
4. Click tag to see all matching notes

### Colors
Color-code for visual organization:
- 🟡 Yellow: Ideas
- 🔵 Blue: Reference
- 🟢 Green: Completed
- 🔴 Red: Urgent
- 🟣 Purple: Personal

### Pinning
Pin important notes:
1. Click the pin icon
2. Note appears at top
3. Persists across sessions
4. Unpin when no longer needed

## Searching Notes

### Quick Search
1. Use search box at top
2. Finds matches in:
   - Title
   - Content
   - Tags

### Filters
- By date created
- By tag
- By color
- Pinned only
- Recently modified

### Full-Text Search
Searches entire note content:
- Phrases: "quarterly review"
- Tags: #follow-up
- Dates: created:2025-01

## Note Actions

### Quick Actions
Right-click any note for:
- **Edit**: Open for changes
- **Delete**: Remove permanently
- **Duplicate**: Copy note
- **Pin/Unpin**: Toggle priority

- **Add Tags**: Categorize

### Bulk Actions
Select multiple notes:
- Mass delete
- Apply tags
- Change colors
- Export together

## Converting Notes

### To Task
Have a note that became actionable?
1. Open the note
2. Click **Convert to Task**
3. Note content becomes task description
4. Add due date and owner
5. Original note can be kept or deleted

### To 1:1 Agenda Item
Want to discuss in a meeting?
1. Open the note
2. Click **Add to 1:1**
3. Select team member and meeting
4. Creates linked agenda item

### To Feedback
Note contains performance observation?
1. Open the note
2. Click **Convert to Feedback**
3. Select team member
4. Note becomes feedback content

## Auto-Save

### How It Works
- Notes save automatically
- Every few seconds
- No save button needed
- Never lose content

### Sync Status
- ✓ Saved
- ⟳ Saving...
- ⚠ Error (will retry)

## Note Templates

### Quick Templates
Start with pre-made formats:
- **Meeting Notes**: Date, attendees, topics, actions
- **Decision Record**: Context, options, decision, rationale
- **Idea Capture**: Idea, benefits, challenges, next steps
- **Weekly Review**: Wins, challenges, next week focus

### Creating Templates
1. Create a note with your format
2. Click **Save as Template**
3. Name your template
4. Use **New from Template** later

## Best Practices

### Capture Quickly
Don't overthink - get it down:
- Speed over perfection
- Clean up later
- Better captured than forgotten

### Review Regularly
Weekly note hygiene:
1. Review recent notes
2. Convert actionable items
3. Archive or delete old notes
4. Organize with tags

### Don't Let Notes Pile Up
Notes are temporary by design:
- Process into proper locations
- Delete when no longer needed
- Keep active count manageable

### Use Tags Consistently
- Develop a tagging system
- Use same tags repeatedly
- Don't create one-off tags
- Clean up unused tags
