# Understanding Key Results

Key Results are the measurable outcomes that determine whether an Objective has been achieved. They're the "how will we know we succeeded?" part of the OKR framework.

## What Is a Key Result?

A Key Result is a specific, measurable target that indicates progress toward an Objective. While Objectives are qualitative and inspirational, Key Results are quantitative and concrete.

### The Relationship

```
OBJECTIVE (Qualitative)          →  What we want to achieve
    ↓
KEY RESULTS (Quantitative)       →  How we'll measure success
```

**Example**:

**Objective**: Build a world-class customer support team

**Key Results**:
1. Improve average CSAT score from 4.1 to 4.6
2. Reduce first response time from 4 hours to 1 hour
3. Achieve 85% first-contact resolution rate (currently 67%)
4. Decrease escalation rate from 12% to 5%

## Key Results vs. Tasks

This is one of the most common confusions in OKR implementation.

| Key Results | Tasks |
|-------------|-------|
| Measure **outcomes** | Describe **activities** |
| Answer "Did we succeed?" | Answer "Did we do the work?" |
| Focus on **impact** | Focus on **effort** |
| Usually 3-5 per objective | Can be many per key result |

### Examples

**Task** (Not a Key Result):
- Implement new chat system
- Hire 3 support agents
- Create training program
- Write knowledge base articles

**Key Result** (Measurable outcome):
- Reduce average response time from 4 hours to 1 hour

The tasks above might all contribute to achieving the Key Result, but they're not the Key Result itself.

## Anatomy of a Great Key Result

### The Formula

```
[Verb] [Metric] from [Baseline] to [Target]

Examples:
- Increase NPS from 42 to 65
- Reduce churn rate from 8% to 4%
- Grow monthly active users from 50K to 100K
- Improve conversion rate from 2.1% to 3.5%
```

### Required Components

| Component | Description | Example |
|-----------|-------------|---------|
| **Verb** | Action direction | Increase, Reduce, Improve, Achieve |
| **Metric** | What you're measuring | NPS, Revenue, Response Time |
| **Baseline** | Starting point | "from 42" |
| **Target** | End goal | "to 65" |

### Why Baselines Matter

Without a baseline:
- "Achieve high customer satisfaction" → How will you know?
- "Improve response time" → From what? To what?

With a baseline:
- "Increase CSAT from 4.1 to 4.6" → Clear measurement
- "Reduce response time from 4h to 1h" → Specific improvement

## Types of Key Results

### Metric Key Results
Most common type—move a number from X to Y.

**Examples**:
- Increase revenue from $1M to $1.5M
- Reduce defect rate from 5% to 2%
- Improve employee engagement score from 65 to 80

### Milestone Key Results
Sometimes appropriate for binary outcomes, but use sparingly.

**Examples**:
- Launch product V2.0 by March 31
- Achieve SOC 2 certification
- Complete migration to new platform

**Warning**: Milestones measure completion, not impact. Prefer metric-based Key Results when possible.

### Quality Key Results
Based on assessments or ratings rather than pure numbers.

**Examples**:
- Achieve 4.5+ star rating on app store (currently 3.8)
- Reach "Great Place to Work" certification
- Attain A+ security rating

## How Many Key Results?

### The Ideal Range: 3-5 per Objective

**Fewer than 3**:
- May not fully capture what success looks like
- Risk of gaming a single metric

**More than 5**:
- Loses focus
- Difficult to track
- Team becomes overwhelmed

### Balancing Key Results

Include a mix to prevent gaming:

**Objective**: Deliver exceptional customer support

**Balanced Key Results**:
1. 📈 Speed: Reduce response time from 4h to 1h
2. 😊 Quality: Increase CSAT from 4.1 to 4.6
3. 🎯 Efficiency: Improve first-contact resolution from 67% to 85%

If you only measured speed, quality might suffer. If you only measured quality, speed might drop.

## Scoring Key Results

At the end of the OKR period, score each Key Result on a 0-1 scale:

### Scoring Scale

| Score | Meaning | Description |
|-------|---------|-------------|
| 0.0 | No progress | Failed to move the needle |
| 0.1-0.3 | Minimal | Some progress but far from target |
| 0.4-0.6 | Partial | Meaningful progress, fell short |
| 0.7-0.9 | Strong | Near target or exceeded expectations |
| 1.0 | Complete | Fully achieved |

### The 70% Sweet Spot

**Key Results should be ambitious.** Consistently scoring 1.0 means your goals weren't challenging enough.

- **0.7-0.9** = Great performance
- **1.0 every time** = Sandbagging (setting easy targets)
- **Below 0.3** = Either too ambitious or poor execution

### Calculating Score

For metric Key Results:

```
Score = (Actual - Baseline) / (Target - Baseline)

Example:
- Baseline: 42
- Target: 65
- Actual: 58

Score = (58 - 42) / (65 - 42) = 16/23 = 0.70
```

## Common Key Result Mistakes

### 1. Activity, Not Outcome
❌ "Complete 10 customer interviews"
✅ "Identify 5 validated customer pain points"

### 2. Binary When It Should Be Measured
❌ "Launch new feature"
✅ "Launch new feature with 80% user adoption"

### 3. No Baseline
❌ "Improve customer satisfaction"
✅ "Increase CSAT from 4.1 to 4.6"

### 4. Too Easy
❌ "Maintain current revenue"
✅ "Grow revenue from $1M to $1.3M"

### 5. Too Aggressive
❌ "10x revenue in one quarter"
✅ "Grow revenue by 30% this quarter"

### 6. Uncontrollable
❌ "Win industry award"
✅ "Submit 3 award applications with complete case studies"

### 7. Gaming Risk
❌ Single metric that can be manipulated
✅ Balanced set of metrics that check each other

## Output vs. Outcome Key Results

### Output Key Results (Less Ideal)
Measure what you produce:
- Launch 3 features
- Write 20 blog posts
- Conduct 50 sales calls
- Complete training program

### Outcome Key Results (Better)
Measure the impact:
- Achieve 75% adoption of new features
- Increase organic traffic by 40%
- Close $500K in new business
- Improve skill assessment scores from 65% to 85%

**The Difference**: Outputs can be completed without achieving the underlying goal. You can launch features no one uses, write posts no one reads, make calls that don't convert.

**Best Practice**: Ask "So what?" If you complete the output, does success follow? Track the outcome instead.

## Key Results and KPIs

Key Results often come from KPIs:

**Existing KPIs**:
- Customer NPS: 42
- Response time: 4 hours
- Conversion rate: 2.1%

**OKR Key Results** (KPIs with ambitious targets):
- Increase NPS from 42 to 65
- Reduce response time from 4h to 1h
- Improve conversion from 2.1% to 3.5%

This creates natural alignment between your ongoing monitoring (KPIs) and your improvement initiatives (OKRs).

## Updating Key Results

### During the OKR Period

**Don't change targets** unless:
- Fundamental business circumstances changed
- The metric definition was flawed
- External factors made the target irrelevant

**Do track progress**:
- Update current values regularly (weekly or bi-weekly)
- Review in team meetings
- Identify blockers and adjust tactics

### At Period End

1. Score each Key Result
2. Reflect on what worked and didn't
3. Consider what you learned
4. Apply insights to next period's Key Results

---

*Key Results transform aspirational Objectives into measurable outcomes. They're the proof that your work is making an impact—not just keeping you busy.*
