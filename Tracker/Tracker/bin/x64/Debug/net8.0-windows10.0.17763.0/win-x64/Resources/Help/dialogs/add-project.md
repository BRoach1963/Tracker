# Add Project Dialog

Create or edit projects.

## Overview

Create projects to track team initiatives at a high level.

## Fields

| Field | Description |
|-------|-------------|
| **Name** | Project title |
| **Description** | What the project is about |
| **Owner** | Team member responsible |
| **Status** | Active, On Hold, Completed, Cancelled |
| **Start Date** | When work began |
| **End Date** | Target completion date |
| **Progress** | Percentage complete |

## Tabs

### Details Tab

Basic project information and dates.

### Milestones Tab

Track key deliverables:

1. Click **Add Milestone**
2. Enter description
3. Set target date
4. Mark complete when achieved

### Risks Tab

Document and track risks:

1. Click **Add Risk**
2. Describe the risk
3. Set impact level
4. Add mitigation plan
5. Update status

### Dependencies Tab

Link related projects:

1. Click **Add Dependency**
2. Select related project
3. Describe the dependency

## Project Status

| Status | When to Use |
|--------|-------------|
| **Active** | Work in progress |
| **On Hold** | Temporarily paused |
| **Completed** | Successfully finished |
| **Cancelled** | No longer needed |

## Progress Tracking

- Manual: Adjust the slider
- Auto: Based on milestone completion

## Tips

> 💡 **Start simple** - Add details as project evolves

> 💡 **Track risks early** - Prevention beats reaction

> 💡 **Update regularly** - Stale data isn't useful
