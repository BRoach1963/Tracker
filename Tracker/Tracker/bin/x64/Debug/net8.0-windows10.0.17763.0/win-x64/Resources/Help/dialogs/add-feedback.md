# Add Feedback Dialog

Create or edit feedback for team members.

## Overview

Document recognition, coaching, and performance feedback.

## Fields

| Field | Description |
|-------|-------------|
| **Team Member** | Who this feedback is for |
| **Type** | Category of feedback |
| **Title** | Brief summary |
| **Date** | When it happened |
| **Content** | Detailed feedback |
| **Context** | Situation/project (optional) |

## Feedback Types

| Type | When to Use |
|------|-------------|
| **Positive** | Good work, wins |
| **Constructive** | Areas for improvement |
| **Recognition** | Public acknowledgment |
| **Coaching** | Developmental guidance |
| **Performance Review** | Formal review notes |

## Writing Good Feedback

### Use the SBI Model

- **Situation** - When and where
- **Behavior** - What you observed  
- **Impact** - Effect on team/project

### Example

**Title:** "Great sprint demo presentation"

**Content:** "In yesterday's sprint demo (Situation), you clearly explained the technical implementation to non-technical stakeholders (Behavior), which helped them understand the value and approve the next phase of work (Impact)."

## Tips

> 💡 **Be timely** - Record while it's fresh

> 💡 **Be specific** - Details make it actionable

> 💡 **Be balanced** - Mix positive and constructive

> 💡 **Link to context** - Note the project or situation
