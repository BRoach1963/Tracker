# Search

Find anything quickly with global search.

## Overview

The Search feature lets you find:

- Team members
- 1:1 meetings
- Tasks
- Projects
- OKRs
- KPIs
- Goals
- Feedback
- Notes

## Using Search

1. Navigate to **Search** in the sidebar
2. Type your search query
3. Press **Enter** or click **Search**
4. Browse results by category
5. Click a result to open it

## Search Tips

### Effective Queries

| Query Type | Example |
|------------|---------|
| **Name** | "John" |
| **Title** | "Q4 planning" |
| **Description** | "performance review" |
| **Combined** | "Sarah project update" |

### Filtering Results

Results are grouped by type:
- Team Members
- Meetings
- Tasks
- Projects
- OKRs/KPIs
- Goals
- Feedback
- Notes

### Recent Searches

Quick access to your recent searches:
- View recent queries
- Click to re-run a search

### Recent Items

See recently accessed items:
- Quick access without searching
- Grouped by type

## Search Scope

Search finds matches in:

| Entity | Searchable Fields |
|--------|------------------|
| **Team Members** | Name, email, title |
| **1:1s** | Description, agenda |
| **Tasks** | Description, notes |
| **Projects** | Name, description |
| **OKRs** | Title, description |
| **KPIs** | Name, description |
| **Goals** | Title, description |
| **Feedback** | Title, content |
| **Notes** | Content, tags |

## Best Practices

> 💡 **Be specific** - More words = more relevant results.

> 💡 **Use names** - Searching by person is fast.

> 💡 **Check all categories** - Results might be in unexpected places.
