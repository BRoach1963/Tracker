# Add Goal Dialog

Create or edit individual development goals.

## Overview

Track personal growth goals for team members.

## Fields

| Field | Description |
|-------|-------------|
| **Title** | Clear goal statement |
| **Category** | Type of development |
| **Description** | Details and context |
| **Target Date** | Optional deadline |
| **Progress** | Percentage complete (0-100) |
| **Status** | Current state |
| **Notes** | Additional information |

## Categories

| Category | Examples |
|----------|----------|
| **Career** | Promotion, role change |
| **Skill Development** | New programming language |
| **Certification** | AWS, PMP, etc. |
| **Leadership** | Leading a team |
| **Communication** | Presentation skills |
| **Technical** | Architecture expertise |
| **Personal** | Work-life balance |

## Adding Milestones

Break goals into steps:

1. Click **Add Milestone**
2. Enter milestone description
3. Mark complete as achieved

## Status Options

| Status | Meaning |
|--------|---------|
| **Not Started** | Haven't begun |
| **In Progress** | Actively working |
| **On Track** | Making good progress |
| **At Risk** | May not complete on time |
| **Completed** | Done! |
| **On Hold** | Paused |
| **Cancelled** | No longer pursuing |

## Tips

> 💡 **SMART goals** - Specific, Measurable, Achievable, Relevant, Time-bound

> 💡 **Use milestones** - Break big goals into steps

> 💡 **Update progress** - Keep it current for 1:1 discussions
