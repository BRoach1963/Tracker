# Quick Notes

Capture thoughts, ideas, and observations quickly.

## Overview

Quick Notes provides a scratchpad for:

- Meeting prep ideas
- Observations about team members
- Ideas for discussion
- Quick reminders
- Decision records

## Creating a Note

1. Navigate to **Notes** in the sidebar
2. Click **Add Note**
3. Enter your note content
4. Optionally:
   - Select a **Category**
   - Link to a **Team Member**
   - Link to a **Project**
   - Add **Tags**
5. Click **Save**

## Note Categories

| Category | Use For |
|----------|---------|
| **General** | Uncategorized notes |
| **Meeting** | Meeting-related notes |
| **Idea** | Ideas to explore |
| **Todo** | Quick reminders |
| **Decision** | Recorded decisions |
| **Observation** | Things you noticed |
| **Reflection** | Personal thoughts |
| **Reminder** | Things to remember |

## Organizing Notes

### Pinning

- Pin important notes to keep them at the top
- Click the pin icon to toggle

### Archiving

- Archive old notes to declutter
- Archived notes are still searchable

### Tagging

- Add tags for flexible organization
- Filter by tags to find related notes

### Linking

Connect notes to context:

- **Team Member** - Notes about a person
- **Project** - Project-related notes
- **1:1 Meeting** - Pre/post meeting notes

## Searching Notes

Use the search box to find notes:

- Search note content
- Filter by category
- Filter by tags
- Show/hide archived

## Using Notes in 1:1s

Capture discussion points throughout the week:

1. Create notes as things come up
2. Link to the team member
3. Before 1:1, review their notes
4. Convert to agenda items
5. Archive after discussing

## Best Practices

> 💡 **Capture quickly** - Don't over-think, just write it down.

> 💡 **Link when possible** - Context helps later.

> 💡 **Review regularly** - Process and act on notes.

> 💡 **Archive, don't delete** - You might need it later.
