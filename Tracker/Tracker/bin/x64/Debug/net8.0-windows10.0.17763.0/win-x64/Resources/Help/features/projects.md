# Projects

Projects are initiatives composed of multiple tasks with defined scope, timeline, and outcomes.

## Project Fundamentals

### What is a Project?
A project is:
- A collection of related tasks
- With a defined start and end
- Owned by a team member
- Working toward a specific outcome

### When to Use Projects
Use projects for:
- Multi-week initiatives
- Work requiring coordination
- Deliverables with milestones
- Anything needing progress tracking

Use standalone tasks for:
- Quick one-off items
- Simple requests
- Things without dependencies

## Creating a Project

### Basic Setup
1. Navigate to **Pulse** → **Projects**
2. Click **+ Add Project**
3. Enter project details:
   - Name (clear, descriptive)
   - Description (scope and goals)
   - Owner (accountable person)
   - Start Date
   - End Date (target)

### Adding Tasks to Projects
After creating the project:
1. Open the project
2. Click **+ Add Task**
3. Tasks inherit project context
4. Progress auto-calculates

## Project Status

### Status Values

| Status | Meaning | Color |
|--------|---------|-------|
| **Not Started** | Planned, not begun | Gray |
| **In Progress** | Actively being worked | Blue |
| **On Hold** | Paused (blocked/deprioritized) | Yellow |
| **Completed** | Done, outcomes achieved | Green |
| **Cancelled** | Will not complete | Red |

### Status Rules
- Status should reflect reality
- Update when state changes
- "Completed" requires all tasks done
- "Cancelled" preserves history

## Progress Tracking

### Automatic Progress
Progress = (Completed Tasks / Total Tasks) × 100

Example:
- 10 tasks total
- 7 completed
- Progress = 70%

### Progress Indicators

| Range | Status | Visual |
|-------|--------|--------|
| 0-25% | Getting started | ▓░░░ |
| 26-50% | Making progress | ▓▓░░ |
| 51-75% | Over halfway | ▓▓▓░ |
| 76-99% | Almost done | ▓▓▓▓ |

## Team Assignment

### Adding Team Members
1. Open the project
2. Go to **Team** section
3. Click **+ Add Member**
4. Select team members
5. Optionally assign roles

### Member Roles
- **Owner**: Accountable for project
- **Contributor**: Assigned tasks
- **Reviewer**: Approval authority
- **Observer**: Visibility only

## Project Filtering

### Quick Filters
- **Active**: In Progress + Not Started
- **My Projects**: Where I'm owner
- **Overdue**: Past end date, not complete
- **This Quarter**: Within current Q

### Advanced Filtering
- By status
- By owner
- By team member
- By date range
- By priority
- Text search

## Linking Projects

### To OKRs
Connect projects to objectives:
1. Open project
2. Click **Link to OKR**
3. Select Key Result
4. Project progress feeds OKR

### To KPIs
Use project completion as a KPI source:
1. Create a KPI
2. Select "Project Completion" as source
3. Choose the project
4. KPI value = project progress %

## Project Templates

Save time with templates:

### Using Templates
1. Click **+ Add Project**
2. Select **From Template**
3. Choose template
4. Customize as needed

### Creating Templates
1. Set up a project fully
2. Click **Save as Template**
3. Name and describe
4. Reuse later

### Built-in Templates
- **Product Launch**: Standard launch checklist
- **Quarterly Planning**: OKR setting process
- **Onboarding**: New hire tasks
- **Performance Review**: Review cycle tasks

## Archiving & Deleting

### Archive
- Completed/cancelled projects
- Preserves all history
- Removes from active views
- Can restore if needed

### Delete
- Permanently removes
- Includes all tasks
- Cannot undo
- Use carefully

## Project Metrics

### Health Indicators
- **Schedule**: On time vs. slipping
- **Scope**: Task count changes
- **Resources**: Team availability
- **Quality**: Issue/bug counts

### Calculated Metrics
- Days until deadline
- Velocity (tasks/week)
- Completion trajectory
- Risk score

## Best Practices

### Project Naming
✅ Good: "Q1 2025 Website Redesign"
❌ Bad: "Website"

Include:
- Time period if relevant
- Specific scope
- Outcome orientation

### Scope Management
- Define what's in AND out
- Document assumptions
- Flag scope changes
- Update estimates

### Progress Updates
- Review weekly minimum
- Update task statuses
- Flag blockers early
- Communicate changes

### Project Closure
1. Verify all tasks complete
2. Conduct retrospective
3. Document learnings
4. Archive project
5. Celebrate success! 🎉
