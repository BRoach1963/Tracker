# Add Reminder Dialog

Create custom reminders.

## Overview

Set reminders for tasks, meetings, and custom events.

## Fields

| Field | Description |
|-------|-------------|
| **Title** | What to remind about |
| **Message** | Details |
| **Due Date/Time** | When to trigger |
| **Type** | Category of reminder |

## Reminder Types

| Type | Auto-created For |
|------|------------------|
| **Meeting** | Upcoming 1:1s |
| **Task** | Task due dates |
| **Goal** | Goal target dates |
| **Custom** | Anything else |

## Quick Select

Use the buttons for common times:
- **1 Hour** - Reminder in 1 hour
- **Tomorrow** - 9 AM tomorrow
- **Next Week** - Same time next week

## Notification

When a reminder triggers:
- Toast notification appears
- Reminder shows in notification center
- Can snooze or dismiss

## Tips

> 💡 **Set meeting reminders** - Don't miss 1:1s

> 💡 **Use for follow-ups** - "Check on X in 3 days"

> 💡 **Be specific** - Include context in the message
