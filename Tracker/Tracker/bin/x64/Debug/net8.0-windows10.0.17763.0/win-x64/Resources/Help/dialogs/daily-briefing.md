# Daily Briefing Dialog

The **Daily Briefing** is a personalized summary that appears when you start Tracker each day. It provides a quick overview of what needs your attention.

## When It Appears

The Daily Briefing shows automatically when:
- You open Tracker for the first time each day
- "Show Daily Briefing on startup" is enabled in settings

## Dialog Layout

### Header Section

![Morning greeting with date]

- **Greeting** - Changes based on time of day:
  - "Good Morning!" (before 12pm)
  - "Good Afternoon!" (12pm - 5pm)
  - "Good Evening!" (after 5pm)
- **Date** - Current date displayed

### Stats Row

Three cards showing at-a-glance numbers:

| Card | Shows |
|------|-------|
| **Meetings Today** | Number of 1:1s scheduled for today |
| **Open Tasks** | Count of incomplete action items |
| **Insights** | Total active insights needing attention |

### Insights Sections

Insights are grouped by urgency:

#### ⚠️ Needs Attention (Red)
Critical items requiring immediate action:
- Team members you haven't met with in 21+ days
- Tasks overdue by 14+ days

#### 📋 Reminders (Orange)
Important items approaching concern thresholds:
- Meeting gaps of 14-20 days
- Work anniversary milestones approaching
- Tasks overdue by 7-13 days

#### 💡 Good to Know (Blue)
Informational awareness items:
- Upcoming birthdays within 7 days
- Regular work anniversaries
- General awareness insights

### All Clear State

When you have no active insights, you'll see:
- A checkmark icon
- "All Clear!" message
- Confirmation that nothing needs attention

## Actions

### Viewing an Insight

Click any insight to:
1. Mark it as read
2. Navigate to the related team member, meeting, or task

### Closing the Briefing

- Click **"Let's Go!"** to close and start working
- Click **✕** in the top-right corner

### Disabling Future Briefings

1. Check **"Don't show on startup"** at the bottom
2. Click **"Let's Go!"**
3. Future startups will skip the briefing

To re-enable:
1. Go to **Settings** → **Insights**
2. Enable **"Show Daily Briefing on startup"**

## Tips

### Make It a Habit
Take 30 seconds each morning to:
1. Review the stats
2. Scan critical items
3. Note any actions for your day

### Don't Ignore Reds
Critical items (red) mean something has been overlooked too long. Prioritize addressing these first.

### Dismiss What's Handled
If you've already addressed something outside Tracker, dismiss that insight from the main insight panel to keep your briefing clean.

## Keyboard Shortcut

There's no keyboard shortcut to manually trigger the Daily Briefing, but you can:
- Press **F1** to open Oracle and ask "Show my insights"
- View all insights via the ✨ sparkle button
