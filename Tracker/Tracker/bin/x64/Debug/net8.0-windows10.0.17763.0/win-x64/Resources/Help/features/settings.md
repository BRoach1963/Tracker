# Settings

Configure Tracker to work the way you want. Access Settings via the gear icon or **Alt+5**.

## Settings Categories

### Appearance

#### Theme Selection
Choose from 8 professionally designed themes:

| Theme | Description |
|-------|-------------|
| **Dark Gold** | Dark background with gold accents (default) |
| **Light Gold** | Light background with gold accents |
| **Midnight Blue** | Deep blue with cyan highlights |
| **Forest** | Dark green nature-inspired |
| **Sunset** | Warm orange and red tones |
| **Ocean** | Blue and teal aquatic theme |
| **Monochrome** | Clean black and white |
| **High Contrast** | Maximum readability |

**To change theme**:
1. Go to **Settings** → **Appearance**
2. Click on a theme
3. Preview updates instantly
4. Theme persists across sessions

#### Font Size
Adjust text size for readability:
- Small
- Medium (default)
- Large
- Extra Large

### Account & Subscription

#### Your Account
View and manage your Tracker account:
- **Email**: Your sign-in email
- **Display Name**: How you appear in the app
- **Profile Photo**: Your avatar
- **Member Since**: Account creation date

Click **Manage Account** to edit your profile or change your password.

#### Subscription Status
See your current plan:

| Your Plan | Features |
|-----------|----------|
| **Free** | 10 team members, local storage |
| **Standard** | 100 members, AI Help, Calendar Sync, Reports |
| **Pro** | Unlimited, AI Data Analysis, Full Reports, Priority Support |

Click **Upgrade** to compare plans and upgrade.

#### Billing
- View next billing date
- Update payment method
- Download invoices
- Cancel subscription

### Data Management

#### Database Location
Where your data is stored:
- View current location
- Change database path
- Create backups
- Restore from backup

**Note**: Pro users can connect to networked SQL Server databases for team sharing.

#### Export All Data
Create a complete backup:
1. Click **Export All**
2. Choose format (JSON/SQLite)
3. Select save location
4. Use for backup or migration

#### Import Data
Restore or migrate:
1. Click **Import**
2. Select backup file
3. Choose merge or replace
4. Confirm import

#### Clear Data
Reset the application:
- Clear all data (requires confirmation)
- Clear specific categories
- Reset to defaults

## Backup Strategy

### Recommended Schedule
- **Daily**: Automatic background backup
- **Weekly**: Manual full export
- **Monthly**: Offsite copy

### Backup Locations
1. Local backup folder
2. Cloud storage (OneDrive/Dropbox)
3. External drive

### Testing Backups
Periodically verify:
1. Create test backup
2. Restore to new location
3. Verify data integrity
4. Confirm everything works

## Reset & Recovery

### Reset Settings
Return to defaults:
1. Go to **Settings** → **Advanced**
2. Click **Reset All Settings**
3. Confirm reset
4. Restart application

### Factory Reset
Complete fresh start:
1. Export your data first!
2. **Settings** → **Advanced**
3. Click **Factory Reset**
4. Confirm you want to delete everything
5. Application restarts empty

### Recovery Options
If something goes wrong:
1. Check recent backups
2. Look in backup folder
3. Contact support with logs
4. Restore from export

## Troubleshooting Settings

### Settings Not Saving
- Check write permissions
- Verify disk space
- Try running as administrator
- Check settings file location

### Theme Not Applying
- Restart application
- Clear theme cache
- Check for conflicts
- Reset appearance settings

### Sync Issues
- Verify internet connection
- Re-authenticate with provider
- Check permissions granted
- Review sync logs
