# Add/Edit Team Member Dialog

This dialog is used to create new team member profiles or edit existing ones.

## Accessing the Dialog

### Add New
- **Circle** → **Team** → **+ Add Team Member**
- Keyboard: `Ctrl+N` when on Team view

### Edit Existing
- Click team member → **Edit** button
- Right-click → **Edit**
- Double-click team member card

## Dialog Sections

### Basic Information

| Field | Required | Description |
|-------|----------|-------------|
| **First Name** | Yes | Team member's first name |
| **Last Name** | Yes | Team member's last name |
| **Email** | Recommended | Primary email address |
| **Phone** | Optional | Phone number |
| **Profile Photo** | Optional | Upload or drag-drop image |

### Role Details

| Field | Description |
|-------|-------------|
| **Job Title** | Current role/position |
| **Department** | Team or department name |
| **Location** | Office location or "Remote" |
| **Start Date** | When they joined the team |
| **Manager** | Their direct manager (if not you) |

### Skills & Competencies

Add skills to track expertise:
1. Click **+ Add Skill**
2. Enter skill name
3. Select proficiency level:
   - Beginner
   - Intermediate  
   - Advanced
   - Expert

### Notes

Free-form field for:
- Personal context
- Working style preferences
- Important information to remember
- Background and history

## Photo Upload

### Supported Formats
- JPG/JPEG
- PNG
- GIF

### Recommendations
- Square images work best
- 200x200 pixels minimum
- Keep file size under 1MB

### How to Add
1. Click the photo placeholder
2. Select file from computer
3. Or drag-drop onto the placeholder

## Validation Rules

### Required Fields
- First Name (minimum 1 character)
- Last Name (minimum 1 character)

### Email Validation
- Must be valid email format
- Checked for duplicates

### Date Validation
- Start date cannot be in the future
- Must be a valid date

## Dialog Actions

| Button | Action |
|--------|--------|
| **Save** | Save changes and close |
| **Cancel** | Discard changes and close |
| **Delete** | Remove team member (edit mode only) |

## Keyboard Shortcuts

| Key | Action |
|-----|--------|
| `Enter` | Save (when in form field) |
| `Escape` | Cancel and close |
| `Tab` | Move to next field |
| `Shift+Tab` | Move to previous field |

## Meeting History Tab

*Available in Edit mode only*

View the complete 1:1 meeting history with this team member:

| Column | Description |
|--------|-------------|
| **Meeting Date** | When the meeting occurred |
| **Status** | Scheduled, Completed, Canceled |
| **Duration** | How long the meeting lasted |
| **Summary** | Brief description or notes |

### Actions
- Double-click a meeting to view full details
- View agenda items and tasks from past meetings
- See patterns in meeting frequency

## Feedback History Tab

*Available in Edit mode only*

Track feedback given to and received from this team member:

| Column | Description |
|--------|-------------|
| **Date** | When feedback was given |
| **Type** | Positive, Constructive, Recognition, Coaching, Performance Review |
| **Title** | Brief summary |
| **Content** | Full feedback details |

### Actions
- **Add Feedback** - Record new feedback
- **Edit** - Modify existing feedback
- **Delete** - Remove feedback record

### Feedback Types

| Type | Color | Use Case |
|------|-------|----------|
| 🟢 Positive | Green | Praise, good work |
| 🟡 Constructive | Yellow | Areas for improvement |
| 🔵 Recognition | Blue | Public acknowledgment |
| 🟣 Coaching | Purple | Guidance and mentoring |
| ⚪ Performance Review | Gray | Formal reviews |

## Goals Tab

*Available in Edit mode only*

Manage individual development goals for this team member:

| Column | Description |
|--------|-------------|
| **Goal Title** | What they're working toward |
| **Category** | Career, Skill Development, Certification, etc. |
| **Status** | Not Started, In Progress, Completed, On Hold |
| **Target Date** | When the goal should be achieved |
| **Progress** | Percentage complete |

### Actions
- **Add Goal** - Create a new goal
- **Edit** - Modify goal details
- **Delete** - Remove a goal
- Click progress bar to update completion

### Goal Categories

| Icon | Category |
|------|----------|
| 🎯 | Career |
| 📚 | Skill Development |
| 📜 | Certification |
| 👥 | Leadership |
| 💬 | Communication |
| 💻 | Technical |
| 🌟 | Personal |

## Tips

### When Adding New Members
- Add at least email for contact
- Set start date for tenure tracking
- Add skills to enable project matching
- Include notes for personal context

### When Editing
- Update title/role promptly when promoted
- Keep skills current
- Add notes after significant conversations
- Update photo if they change
- Record feedback frequently, not just during reviews
