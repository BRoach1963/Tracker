# Add Team Member Dialog

Add or edit team member information.

## Overview

This dialog allows you to create new team members or edit existing ones.

## Fields

### Required Fields

| Field | Description |
|-------|-------------|
| **First Name** | Team member's first name |
| **Last Name** | Team member's last name |
| **Email** | Primary email address |

### Optional Fields

| Field | Description |
|-------|-------------|
| **Phone** | Contact phone number |
| **Job Title** | Official job title |
| **Role** | Engineering role (Backend, Frontend, etc.) |
| **Specialty** | Technical specialty area |
| **Skill Level** | Junior, Mid, Senior, etc. |
| **Hire Date** | When they joined the team |
| **Birthday** | For birthday reminders |
| **Profile Picture** | Photo for visual identification |

## Details Tab

Basic information and employment details including:

- Personal information (name, contact)
- Employment details (role, title, hire date)
- Skills and specializations
- Status (Active/Inactive)

## Meeting History

*Available in Edit mode only*

View the complete 1:1 meeting history with this team member:

- **Meeting Date** - When the meeting occurred
- **Status** - Scheduled, Completed, Canceled
- **Duration** - How long the meeting lasted
- **Summary** - Brief description or notes

### Actions
- Double-click a meeting to view full details
- View agenda items and tasks from past meetings
- See patterns in meeting frequency

## Feedback History

*Available in Edit mode only*

Track feedback given to and received from this team member:

- **Date** - When feedback was given
- **Type** - Positive, Constructive, Recognition, Coaching, Performance Review
- **Title** - Brief summary
- **Content** - Full feedback details

### Actions
- **Add Feedback** - Record new feedback
- **Edit** - Modify existing feedback
- **Delete** - Remove feedback record

### Feedback Types
| Type | Color | Use Case |
|------|-------|----------|
| 🟢 Positive | Green | Praise, good work |
| 🟡 Constructive | Yellow | Areas for improvement |
| 🔵 Recognition | Blue | Public acknowledgment |
| 🟣 Coaching | Purple | Guidance and mentoring |
| ⚪ Performance Review | Gray | Formal reviews |

## Goals Tab

*Available in Edit mode only*

Manage individual development goals for this team member:

- **Goal Title** - What they're working toward
- **Category** - Career, Skill Development, Certification, etc.
- **Status** - Not Started, In Progress, Completed, On Hold
- **Target Date** - When the goal should be achieved
- **Progress** - Percentage complete

### Actions
- **Add Goal** - Create a new goal
- **Edit** - Modify goal details
- **Delete** - Remove a goal
- Click progress bar to update completion

### Goal Categories
- 🎯 Career
- 📚 Skill Development
- 📜 Certification
- 👥 Leadership
- 💬 Communication
- 💻 Technical
- 🌟 Personal

## Adding a Profile Picture

1. Click **Choose Photo**
2. Select an image file
3. Image is resized automatically

Supported formats: JPG, PNG, GIF

## Saving

- Click **Save** to save changes
- Click **Cancel** to discard changes
- Required fields must be filled

## Tips

> 💡 **Email is used for identification** - Make sure it's accurate.

> 💡 **Hire date matters** - Used for tenure calculations.

> 💡 **Profile pictures help** - Makes the UI more personal.

> 💡 **Regular feedback builds trust** - Record feedback frequently, not just during reviews.
