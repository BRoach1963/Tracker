# Add 1:1 Meeting Dialog

Create or edit one-on-one meetings.

## Overview

This dialog helps you plan, document, and track 1:1 meetings with your team members.

## Basic Information

| Field | Description |
|-------|-------------|
| **Team Member** | Who you're meeting with |
| **Date** | Meeting date |
| **Start Time** | When it starts |
| **Duration** | How long (default 30 min) |
| **Status** | Scheduled, Completed, Cancelled |
| **Description** | Brief meeting summary |

## Agenda Items

Plan and track discussion topics for your meeting.

### Adding Agenda Items

1. Click **Add Agenda Item**
2. Select category:
   - **Topic** - General discussion point
   - **Question** - Something to ask
   - **Concern** - Issue to address
   - **Update** - Status to share
   - **Feedback** - Recognition or coaching
3. Enter description
4. Set priority (High/Medium/Low)

### Managing Agenda Items

| Action | How |
|--------|-----|
| Add | Click **+** button |
| Edit | Double-click item or select and click edit |
| Delete | Select item and click delete |
| Reorder | Drag and drop (if supported) |

### Agenda Item Categories

| Category | Icon | Use Case |
|----------|------|----------|
| Topic | 💬 | General discussion points |
| Question | ❓ | Things to ask the team member |
| Concern | ⚠️ | Issues or problems to discuss |
| Update | 📢 | Status updates to share |
| Feedback | ⭐ | Praise or constructive feedback |

## Notes Agenda

Free-form notes area for the meeting.

### Using Notes

- Enter any text notes before, during, or after the meeting
- Great for capturing quick thoughts
- Supports multi-line text
- No formatting required

### Tips for Notes

- Write key discussion points
- Capture decisions made
- Note follow-up items
- Record team member's feedback

## Tasks

Create and manage action items that come out of the meeting.

### Creating Tasks

1. Click **Add Task**
2. Enter task description
3. Set due date
4. Assign owner (you or team member)
5. Set priority

### Task Fields

| Field | Description |
|-------|-------------|
| **Description** | What needs to be done |
| **Owner** | Who is responsible |
| **Due Date** | When it's due |
| **Priority** | High, Medium, Low |
| **Status** | Not Started, In Progress, Completed |

### Task Rollover

Uncompleted tasks from previous meetings can be rolled over:

1. Click **Load Previous Meeting**
2. Review summary of last meeting
3. Click **Rollover Tasks** to bring uncompleted tasks forward
4. Tasks are copied to current meeting

## Linked Items

Connect existing items to discuss during the meeting.

### What Can Be Linked

| Item Type | Purpose |
|-----------|---------|
| **Tasks** | Review existing task progress |
| **OKRs** | Discuss objectives and key results |
| **KPIs** | Review performance metrics |
| **Projects** | Get project status updates |

### How to Link Items

1. Go to the **Linked Items** tab
2. Select the item type
3. Check items to discuss
4. Items appear in linked items list

### Benefits of Linking

- **Context** - See related work during discussion
- **Tracking** - Know what was discussed when
- **Follow-up** - Easy reference for action items

## Using Templates

Speed up meeting creation with templates:

1. Select a **Template** from the dropdown
2. Pre-configured agenda items are added automatically
3. Customize items as needed
4. Save time on recurring meeting formats

### Available Templates

Templates can include default agenda items for:
- Regular 1:1s
- Performance reviews
- Career development
- Project check-ins

## Meeting Status

| Status | Icon | Meaning |
|--------|------|---------|
| **Scheduled** | 📅 | Meeting is planned |
| **Completed** | ✅ | Meeting happened |
| **Cancelled** | ❌ | Meeting was cancelled |

## Saving

- Click **Save** to save changes
- Use **Cancel** to discard all changes
- Required: Team Member, Date, Start Time

## Tips

> 💡 **Prepare ahead** - Add agenda items throughout the week as topics come up.

> 💡 **Use templates** - Save time with recurring meeting formats.

> 💡 **Rollover tasks** - Ensure nothing falls through the cracks between meetings.

> 💡 **Link items** - Context makes discussions more productive.

> 💡 **Take notes** - Document decisions and commitments.
