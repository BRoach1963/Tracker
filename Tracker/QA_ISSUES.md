## Severity Definitions

- 🔴 **Critical**: App crashes, data loss, security issue, blocking functionality
- 🟠 **High**: Major feature broken, significant UX problem, no workaround
- 🟡 **Medium**: Feature partially broken, has workaround, cosmetic issues affecting usability
- 🟢 **Low**: Minor cosmetic issue, enhancement suggestion, edge case

## Status Values

- **Open**: Issue identified, not yet addressed
- **In Progress**: Being worked on
- **Fixed**: Code fix applied, needs verification
- **Verified**: Fix confirmed working
- **Won't Fix**: Intentional behavior or deferred
