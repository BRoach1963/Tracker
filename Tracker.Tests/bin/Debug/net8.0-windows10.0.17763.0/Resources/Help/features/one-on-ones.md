# 1:1 Meetings

One-on-one meetings are the **single most important tool** for managers to build relationships, provide support, and develop their direct reports. Tracker makes it easy to schedule, prepare for, and document these crucial conversations.

## Why 1:1s Matter

Regular 1:1s help you:
- Build trust and psychological safety
- Catch problems early
- Support career development
- Give and receive feedback
- Remove blockers
- Maintain alignment

**Research shows** managers who have regular 1:1s have more engaged, productive teams with lower turnover.

## Creating a 1:1 Meeting

### Basic Setup
1. Navigate to **Circle** → **1:1s**
2. Click **+ Add 1:1**
3. Select the team member
4. Set date, start time, and duration
5. Choose meeting status
6. Save

### Meeting Properties

| Field | Description |
|-------|-------------|
| **Team Member** | Who you're meeting with |
| **Date** | When the meeting occurs |
| **Start Time** | Meeting start |
| **Duration** | 30 min, 45 min, 60 min, or custom |
| **Status** | Scheduled, Completed, Cancelled |
| **Location** | Office, video call, phone |
| **Notes** | Meeting discussion notes |
| **Agenda Items** | Topics to discuss |

### Recurring Meetings
Set up a repeating schedule:
1. Check **Is Recurring**
2. Select frequency (Weekly, Bi-weekly, Monthly)
3. Next meeting auto-creates when current completes

## Agenda Items

### What Are Agenda Items?
Agenda items are **specific topics** you want to discuss in the meeting. They:
- Provide structure to the conversation
- Help both parties prepare
- Create trackable records
- Can link to other Tracker items

### Adding Agenda Items
1. Open the 1:1
2. Scroll to **Agenda Items** section
3. Click **+ Add Item**
4. Enter the topic
5. Optional: Set category and priority

### Agenda Item Properties

| Property | Description |
|----------|-------------|
| **Description** | What you want to discuss |
| **Category** | Type of topic (see below) |
| **Priority** | Importance level |
| **Resolution** | What was decided/discussed |
| **Is Completed** | Checkbox when resolved |
| **Linked Items** | Connected tasks, OKRs, etc. |

### Agenda Categories

| Category | Examples |
|----------|----------|
| **Check-in** | How are you doing? Anything on your mind? |
| **Priorities** | What are you working on? Any blockers? |
| **Feedback** | Recognition, coaching, performance |
| **Career** | Growth, goals, aspirations |
| **Team** | Relationships, collaboration, concerns |
| **Process** | How we work, improvements |
| **Personal** | Work-life, time off, personal matters |

### Linking Agenda Items

Connect agenda items to give context. **Each agenda item can have multiple links**, allowing you to group related topics together.

**How to Link**:
1. Click the link icon (🔗) on an agenda item
2. Search or browse available items
3. Select an item to link it
4. The link appears as a tag showing type and title
5. **Click the link icon again** to add more links

**Link to Tasks**:
- Discuss task status
- Track commitments
- Follow up on overdue items

**Link to OKRs**:
- Review objective progress
- Discuss Key Result updates
- Align on priorities

**Link to KPIs**:
- Discuss metric performance
- Identify improvement areas
- Set targets

**Link to Projects**:
- Project status updates
- Blocker discussions
- Resource needs

**Example Multi-Link Scenario**:
An agenda item "Q1 Sales Review" might link to:
- OKR: "Increase revenue by 20%"
- KPI: "Monthly Recurring Revenue"
- Task: "Prepare sales forecast"

All three appear as tags, making it easy to reference each during the conversation.

## Meeting Notes

### Rich Text Editor
Take notes with full formatting:
- **Bold** (`Ctrl+B`) and *Italic* (`Ctrl+I`)
- Underline
- Bullet and numbered lists
- Font size and family options
- Notes auto-save

### What to Capture
Good meeting notes include:
- Key discussion points
- Decisions made
- Action items (create as tasks!)
- Follow-up topics for next time
- Personal context shared

### Note-Taking Tips
- Focus on **listening first**, notes second
- Capture **commitments** explicitly
- Note **emotions and concerns**, not just facts
- Record **your own action items** too
- Review notes before the next 1:1

## 1:1 Best Practices

### Scheduling
- **Weekly or bi-weekly** for most team members
- **Same time** each week for consistency
- **30-60 minutes** depending on needs
- **Don't cancel** - reschedule if absolutely needed

### Preparation
- Review previous meeting notes
- Check their recent activity (tasks, OKRs)
- Add agenda items in advance
- Ask them to add items too

### During the Meeting
1. **Start with them**: Let them set the tone
2. **Listen more than talk**: 70/30 rule
3. **Ask open questions**: "How do you feel about..."
4. **Be present**: Close laptop, silence phone
5. **Take light notes**: Don't let it interrupt flow

### After the Meeting
- Complete agenda item resolutions
- Create tasks for action items
- Send summary if helpful
- Schedule next meeting if not recurring

### Common Mistakes
❌ Cancelling frequently
❌ Making it all about status updates
❌ Doing all the talking
❌ Not following up on commitments
❌ Skipping preparation
❌ Using it for work you could do async

## 1:1 Question Bank

Need conversation starters? Try these:

### Building Relationship
- "What's been on your mind lately?"
- "What's going well that I should know about?"
- "Is there anything you'd like to talk about that we haven't?"

### Career & Growth
- "What skills do you want to develop?"
- "Where do you see yourself in 2 years?"
- "What would make this job more satisfying?"

### Work & Priorities
- "What's your biggest challenge right now?"
- "What would you do differently if you could?"
- "What should I know that I might not?"

### Feedback & Support
- "What feedback do you have for me?"
- "How can I better support you?"
- "Is there anything I could do differently?"
