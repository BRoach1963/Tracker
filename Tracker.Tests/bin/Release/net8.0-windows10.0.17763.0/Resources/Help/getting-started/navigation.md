# Navigating Tracker

Tracker uses a five-pillar navigation system designed for efficient workflow management.

## Main Navigation Tabs

### 🏠 Home (Dashboard)
Your command center showing:
- **Upcoming meetings** - Next 7 days of 1:1s
- **Task summary** - Overdue, due today, upcoming
- **Team overview** - Active member count and status
- **OKR progress** - Current quarter performance
- **KPI health** - At-a-glance metric status
- **Recent activity** - Latest changes across all areas

**Keyboard shortcut**: `Alt+1`

### 👥 Circle (People & Relationships)
Everything about your team and interactions:

| Sub-tab | Purpose |
|---------|---------|
| **Team** | Manage team member profiles |
| **1:1s** | Schedule and document meetings |
| **Feedback** | Record performance feedback |
| **Goals** | Track individual development goals |

**Keyboard shortcut**: `Alt+2`

### 📊 Pulse (Work & Performance)
Track deliverables and metrics:

| Sub-tab | Purpose |
|---------|---------|
| **Projects** | Multi-task initiatives |
| **Tasks** | Individual work items |
| **OKRs** | Objectives & Key Results |
| **KPIs** | Performance metrics |

**Keyboard shortcut**: `Alt+3`

### 📝 Chronicle (Records & Reports)
Documentation and analysis:

| Sub-tab | Purpose |
|---------|---------|
| **Notes** | Quick notes and thoughts |
| **Reports** | Generated reports and exports |

**Keyboard shortcut**: `Alt+4`

### ⚙️ Settings
Application configuration:
- Theme selection (8 themes available)
- Data management
- Calendar sync
- AI assistant settings
- Export/Import options

**Keyboard shortcut**: `Alt+5`

## Quick Actions

### Global Search
Press `Ctrl+K` to open the search overlay:
- Search across all entities
- Quick navigation to any item
- Recent searches remembered

### Help Assistant
Press `F1` or `Ctrl+Shift+H` to open the AI Help Bot:
- Ask questions about features
- Get help with your data
- Best practice guidance

### Context Menus
Right-click on most items for quick actions:
- Edit
- Delete
- Duplicate
- View details

## Filtering & Sorting

Most list views support:
- **Search box** - Type to filter
- **Column headers** - Click to sort
- **Filter dropdowns** - By status, owner, date range
- **View toggles** - List, card, or calendar views
