
# Metrics – Interaction Flows

## Flow 1: Create Metric
1. User selects Add Metric
2. Enters required fields
3. Optionally links to a goal
4. Metric appears in relevant surfaces

---

## Flow 2: Update Metric
1. Metric appears as due or off-track
2. User opens update panel
3. Enters value and optional note
4. Signal recalculates
5. Entry written to Chronicle

---

## Flow 3: Metric → Task
1. Metric update reveals risk or change
2. User creates task from metric
3. Task links back to metric context

---

## Flow 4: Metric in Meeting
1. Metric appears in agenda context
2. Discussed live
3. Updated during meeting if needed
4. Notes attach to update

---

## Flow 5: Review in Circle
1. Manager views team metrics
2. Identifies trends and ownership
3. Uses metrics to guide conversation
