# ProCohere – Circle Screen Specification (v1)

## Purpose

The Circle screen is a manager-only view designed to understand team activity and determine where attention is needed.

## Eligibility

Only users with direct reports can access Circle.

## Design Principles

- Signal over detail
- No ranking
- No comparison
- Drill-down by intent

## Team Member Cards

Cards surface only high-level indicators:
- Time since last 1:1
- Recent activity presence
- Feedback cadence indicators
No content is shown directly on cards.

## Flyout Panel Tabs

Info: Role and relationship metadata
Goals: Shared or manager-relevant goals
Tasks: Tasks assigned by the manager or shared upward
Meetings: Cadence and metadata only
Feedback: Feedback the manager authored or is permitted to view

## Oracle Insights

Highlights trends and preparation needs. Oracle never evaluates people or assigns blame.
