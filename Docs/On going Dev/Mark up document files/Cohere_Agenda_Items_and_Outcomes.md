# Cohere – Agenda Items & Outcomes

## Scenario 1: Metric Discussion with No Performance Issue

Agenda Item links to a Metric. Notes capture context. Outcome records feedback and decisions. Optional tasks only if action is required. Sensitive notes are permission-scoped.

## Scenario 2: Metric Indicates Systemic Issue

Metric discussed as signal. Tasks created to investigate and remediate. Goal health optionally updated.

## Scenario 3: Task Status Green but Quality Red

Metric or milestone discussed. Decision recorded. Tasks created to adjust process. Follow-up agenda item scheduled.

## Scenario 4: Positive Feedback Only

Agenda item captures recognition. Feedback outcome recorded. No task created.

## Scenario 5: Goal Adjustment

Agenda item links to goal. Decision outcome updates goal scope or timeline. Tasks created only for next concrete steps.

## Outcome Model

Agenda items produce outcomes. Outcomes may create or update tasks, goals, or follow-up agenda items. Metrics are discussable but never actionable.

## UI Principles

Agenda items remain lightweight. Progressive disclosure reveals outcomes, notes, and links only when needed.
